I am the lead developer of `temporal_networks`, an open-source Python package designed to make temporal-network analysis reproducible and reusable. The project translates methods developed in applied network research into documented software with automated tests and version-controlled workflows.

**Tools:** Python, NetworkX, igraph, automated testing, documentation, GitHub.

The package is being prepared for submission to pyOpenSci.
